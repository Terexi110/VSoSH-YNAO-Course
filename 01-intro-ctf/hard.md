# Глава 1 (hard). Стратегия тура и первичная проверка файлов

## 1. Баллы и порядок решения

При **динамическом скоринге** в CTFd цена задачи падает с числом решений. На **ВСоШ** скоринг фиксированный; сверяйся с правилами тура.

Сначала реши всё знакомое и быстрое, затем выбери 1–2 дорогие посильные задачи. При динамическом скоринге учитывай не только текущие баллы, но и время решения: редкая задача дороже, но может отнять весь тур.

Не застревай на одном месте:

- Нет прогресса **20–30 минут** — запиши, что пробовал и получил, и переключись. Заметки помогут вернуться без повторной работы.
- Вместо обоснованного решения приходится угадывать — перечитай условие.
- Перед сложными гипотезами проверь простое: `strings`, `file`, исходник страницы.

## 2. Скрипт первичной проверки

Сохрани повторяющиеся проверки в `~/triage.sh`:

```bash
#!/bin/bash
# использование: ./triage.sh файл
f="$1"
echo "=== file ==="; file "$f"
echo "=== размер ==="; ls -la "$f"
echo "=== флаг открытым текстом? ==="; strings -n 5 "$f" | grep -iE 'flag|ctf|\{.*\}'
echo "=== вложения (сигнатуры) ==="; grep -aboE 'PK|PNG|JFIF|%PDF|GIF8' "$f" | head
```

```bash
chmod +x ~/triage.sh      # сделать исполняемым (один раз)
~/triage.sh задача.bin    # прогнать по любому файлу
```

Скрипт покажет тип и размер файла, возможные флаги и сигнатуры вложений.

## 3. Поиск флагов по всей папке

Для дерева файлов используй регулярное выражение:

```bash
grep -raoE '[a-zA-Z0-9_]+\{[^}]{3,}\}' .   # любой "слово{...}" во всех файлах подпапок
```

Если формат флага нестандартный (например, без скобок, но известен префикс) - подставь свой шаблон:

```bash
grep -raoE 'CTF[0-9A-Z_]{6,}' .
```

## 4. Как выбрать категорию

| Сигнал | Категория | Куда |
|---|---|---|
| дан только текст/числа | Crypto | `04-crypto` |
| дан файл (картинка, дамп, бинарь) | Forensics/Stego/Reverse | `05`, `08` |
| дана ссылка на сайт | Web | `06-web` |
| дан `IP:порт` | Networking/Pwn | `07`, `09` |
| "восстановите", "что выведет программа" | Reverse | `08-reverse` |

Для каждой задачи создай папку (`mkdir task_<имя>`), скрипты решения храни отдельно от скачанных файлов. Сразу сохраняй или коммить находки: виртуалка может зависнуть.

🎯 **Тренировка (hard).** Собери `~/triage.sh` и проверь им 3–4 разных файла: картинку, архив, текст с флагом.
