# Глава 1 (hard). Стратегия тура и быстрая триажа

На этом уровне - не "что такое флаг", а **как выжимать максимум баллов за ограниченное время** и как
не утонуть в одной задаче.

## 1. Динамический скоринг и порядок решения

На CTFd часто включён **динамический скоринг**: чем больше людей решили задачу, тем **меньше** она
стоит. (На **ВСоШ** всегда фиксированный скоринг) Практические выводы:

- "Лёгкие" задачи с высоким числом решений дают мало очков, но берутся быстро - собирай их в начале,
  чтобы не остаться с нулём.
- Задачи с малым числом решений стоят дорого - но туда идёшь, когда лёгкое выбрано.
- Баллы могут меняться по ходу - не ориентируйся только на текущую цену, смотри и на свою скорость.

Правильная тактика: **первый проход - снять всё, что опознаёшь мгновенно**; второй проход - вложиться
в 1-2 дорогие задачи, которые реально вытянешь.

## 2. Борьба с "кроличьими норами"

Главный пожиратель времени - застрять в одной задаче. Правила:

- Засекай время. Нет прогресса **20-30 минут** - пометь задачу "вернуться" и переключись.
- Веди заметки по каждой задаче или сохраняй историю: что пробовал, что получил. Вернувшись, не начнёшь с нуля.
- Если задача требует "угадать" (а не вывести) - скорее всего ты на неверном пути; перечитай условие.

💡 Частая ошибка сильных участников - переусложнять. Сначала всегда проверяй простое (strings, file,
исходник страницы), и только потом сложные гипотезы.

## 3. Автоматическая триажа: скрипт первых секунд

Чтобы не вводить руками одно и то же над каждым файлом, держи в голове (и умей быстро набрать)
скрипт-разведчик. Положи его в `~/triage.sh`:

```bash
#!/bin/bash
# использование: ./triage.sh файл
f="$1"
echo "=== file ==="; file "$f"
echo "=== размер ==="; ls -la "$f"
echo "=== флаг открытым текстом? ==="; strings -n 5 "$f" | grep -iE 'flag|ctf|\{.*\}'
echo "=== вложения (сигнатуры) ==="; grep -aboE 'PK|PNG|JFIF|%PDF|GIF8' "$f" | head
```

```bash
chmod +x ~/triage.sh      # сделать исполняемым (один раз)
~/triage.sh задача.bin    # прогнать по любому файлу
```

За одну команду ты получаешь тип, наличие флага, признаки вложенных файлов и магические байты.

## 4. Извлечение флагов регуляркой по всей папке

Когда файлов много, не ищи вручную - одной командой по всему дереву:

```bash
grep -raoE '[a-zA-Z0-9_]+\{[^}]{3,}\}' .   # любой "слово{...}" во всех файлах подпапок
```

Если формат флага нестандартный (например, без скобок, но известен префикс) - подставь свой шаблон:

```bash
grep -raoE 'CTF[0-9A-Z_]{6,}' .
```

## 5. Чек-лист опознания категории за 5 секунд

| Сигнал | Категория | Куда |
|---|---|---|
| дан только текст/числа | Crypto | `04-crypto` |
| дан файл (картинка, дамп, бинарь) | Forensics/Stego/Reverse | `05`, `08` |
| дана ссылка на сайт | Web | `06-web` |
| дан `IP:порт` | Networking/Pwn | `07`, `09` |
| "восстановите", "что выведет программа" | Reverse | `08-reverse` |

## 6. Гигиена рабочего места на туре

- Каждая задача - в своей папке (`mkdir task_<имя>`), скрипты решения - отдельно от скачанных файлов.
- Коммить/сохраняй промежуточные находки сразу - виртуалка может подвиснуть.

🎯 **Тренировка (hard).** Собери свой `~/triage.sh`, положи рядом 3-4 разных файла (картинку, архив,
текст с флагом) и прогони скрипт по каждому. Доведи запуск триажи до автоматизма - на туре это
экономит минуты на каждой задаче.
