# Глава 1. Что такое CTF и первые 60 секунд

## 1.1. Флаг - это цель

**Флаг** — строка для сдачи в проверяющую систему, например **CTFd**. Обычно он выглядит так:

```
flag{...}
```

Внутри часто встречается текст с заменой букв цифрами (*leet*): `flag{x0r_1s_e4sy}`, `flag{c4esar_sh1ft}`. Точный формат смотри в правилах.

Для начала поищи строки со скобками: `strings файл | grep '{'` (подробнее в главе 2). Это кандидаты на флаг, а не гарантия.

## 1.2. Формат Jeopardy

На муниципальном этапе используется **Jeopardy**: задачи по категориям с баллами, порядок решения свободный.

| Категория | Что обычно дают | Что нужно сделать |
|---|---|---|
| **Crypto** | зашифрованный текст или скрипт шифрования | расшифровать -> флаг |
| **Forensics** | картинка, дамп трафика, странный файл | найти спрятанное -> флаг |
| **Stego** | картинка/аудио "с секретом" | достать скрытые данные -> флаг |
| **Web** | ссылка на сайт или его исходник | найти уязвимость -> флаг |
| **Reverse** | скомпилированная программа или скрипт | понять логику, подобрать вход -> флаг |
| **Networking** | адрес `ip:port`, схема сети | подключиться / разобрать -> флаг |
| **Pwn** | бинарник + `ip:port` | сломать программу вводом -> флаг |
| **Misc** | архивы, QR, кодировки - "всё остальное" | разное |

Просмотри всю доску: сначала решай знакомое и быстрое, сложное оставь на потом.

## 1.3. Первые 60 секунд с файлом

Начни с этих проверок:

```bash
# 1. Каждую задачу - в свою отдельную папку
mkdir task && cd task
# (кладёшь сюда скачанный файл)

# 2. Что это за файл на самом деле?
file данный_файл

# 3. Есть ли внутри читаемый текст и флаг?
strings данный_файл | grep -i '{'

# 4. Посмотреть начало файла байтами (магические байты)
xxd данный_файл | head
```

Так ты узнаешь тип файла, увидишь первые байты и, возможно, открытый флаг. Команды разберём в главе 2.

⚠️ **Каждую задачу держи в отдельной папке. Не запускай скачанный код без проверки.** Скрипты решения храни отдельно от файлов задачи (подробнее в главе 8).

🎯 **Тренировка 1.** Проверь так картинку или бинарник из `/bin/` на виртуалке. Найди в выводе `file` обозначения `image`, `ELF`, `ASCII text`.

## 1.4. На туре

- Сразу поставь файлы задач на скачивание: общий канал может тормозить. Пока они качаются, читай условия.
- Для арифметики, систем счисления и степеней по модулю используй интерактивный `python3`.
- Сохраняй скрипты и находки по ходу: виртуалка может зависнуть.
- Неясно условие — отправь письменный вопрос жюри по форме. Для споров о баллах есть апелляция.
- ⚠️ Работай только со своими задачами и рабочим местом. Чужие сессии, машины и ресурсы вне стендов олимпиады не трогай.
