# Глава 1 (easy). Что такое CTF - самая база

**CTF** - это соревнование, где нужно находить спрятанные строки-**флаги** и сдавать их в
проверяющую систему. За каждый флаг - баллы.

## Флаг

Флаг выглядит так:

```
flag{...}
```

Внутри фигурных скобок - текст, который и надо найти. Увидел `{ }` с текстом - это почти наверняка
флаг.

## Категории (просто чтобы знать слова)

- **Crypto** - что-то зашифровано, надо расшифровать.
- **Forensics / Stego** - что-то спрятано в файле (картинке, дампе).
- **Web** - надо найти уязвимость на сайте.
- **Reverse** - понять, что делает программа.
- **Misc** - всё остальное (архивы, коды).

Решать можно в любом порядке - бери то, что понятнее.

## Главное действие с любым файлом

Открой терминал и в папке с файлом набери:

```bash
strings файл | grep flag
```

`strings` вытаскивает из файла текст, `grep flag` оставляет строки со словом flag. Очень часто флаг
находится **сразу этой одной командой**.

🎯 **Тренировка.** Создай файл с флагом внутри (`echo "привет flag{hello} пока" > t.txt`) и достань
флаг командой `grep flag t.txt`.

> Это всё, что нужно для старта. Когда освоишься - переходи на **medium**.
