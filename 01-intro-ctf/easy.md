# Глава 1 (easy). Что такое CTF

**CTF** — соревнование по поиску спрятанных строк — **флагов**. Сдаёшь флаг в проверяющую систему, получаешь баллы.

## Флаги и категории задач

Обычно флаг выглядит так:

```
flag{...}
```

Нужно найти всю строку вместе со скобками. Точный формат указан в правилах: не всякий текст в `{ }` — флаг.

- **Crypto** — расшифровать данные.
- **Forensics / Stego** — найти скрытые данные в файле, картинке или дампе.
- **Web** — найти уязвимость сайта.
- **Reverse** — разобраться в работе программы.
- **Misc** — прочее: архивы, коды и другие задачи.

Начинай с того, что понятнее, — порядок свободный.

## Первая проверка файла

В терминале, в папке с файлом:

```bash
strings файл | grep flag
```

`strings` извлекает читаемый текст, `grep flag` оставляет строки с `flag`. Если флаг хранится открыто, этого может хватить.

🎯 **Тренировка.** Создай файл: `echo "привет flag{hello} пока" > t.txt`. Найди флаг командой `grep flag t.txt`.
