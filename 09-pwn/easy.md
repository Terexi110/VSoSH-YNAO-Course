# Глава 9 (easy). Pwn - самая база (только идея)

**Pwn** - сломать программу хитрым вводом, чтобы она сделала не то, что задумано. Это сложная
категория; на easy - только понять идею.

## Главная идея: переполнение буфера

Программа выделила место под ввод фиксированного размера (например, 8 символов). Если ввести
**больше**, лишнее "вылезет" за это место и затрёт то, что лежит рядом в памяти.

```c
char buf[8];        // место на 8 символов
int is_admin = 0;   // лежит сразу рядом
gets(buf);          // читает ВВОД без проверки длины - опасно!
```

Если ввести 8 символов + ещё - лишние байты попадут в `is_admin`, и `0` превратится в не-ноль
("ты админ"):

```
ввод:  AAAAAAAA + X
       \- buf -/  \-> затёрло is_admin
```

## Как опознать pwn-задачу

- Дали **программу + адрес `IP:ПОРТ`**.
- Программа читает ввод и, видимо, без проверки длины.

На easy достаточно понимать: **слишком длинный ввод может сломать логику**. Как это точно сделать -
на medium/hard.

🎯 **Тренировка.** Просто запомни картинку: переменные в памяти лежат рядом, и длинный ввод затирает
соседа. Это фундамент всего pwn.
