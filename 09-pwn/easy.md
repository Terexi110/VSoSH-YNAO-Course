# Глава 9 (easy). Pwn: основы

**Pwn** — эксплуатация ошибок программы через специально подобранный ввод. На easy разберём
только идею переполнения буфера.

## Переполнение буфера

Если читать ввод в буфер фиксированного размера без проверки длины, лишние байты могут затереть
соседние данные. Упрощённый пример:

```c
char buf[8];        // место на 8 символов
int is_admin = 0;   // лежит сразу рядом
gets(buf);          // читает ВВОД без проверки длины - опасно!
```

Если `is_admin` расположен сразу после `buf`, ввод длиннее 8 байт может сделать его ненулевым
и дать права администратора:

```
ввод:  AAAAAAAA + X
       \- buf -/  \-> затёрло is_admin
```

Реальное расположение переменных зависит от компилятора; схема показывает принцип.

## Как узнать pwn-задачу

- Дали **программу и адрес `IP:ПОРТ`**.
- Программа читает ввод без проверки длины.

🎯 **Тренировка.** Объясни по схеме, как длинный ввод меняет соседнюю переменную.
