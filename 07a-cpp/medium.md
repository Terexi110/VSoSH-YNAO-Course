# C/C++ (medium). Читаем чужой код: массивы, строки, указатели

Главный навык этой темы - **читать** C, а не писать. Почти всё, что ты увидишь в Ghidra на реверсе,
собрано из того, что ниже. Все примеры можно собрать: `gcc -o prog prog.c && ./prog`.

---

## 1. Массивы и строки - это `char[]`

Строка в C - это **массив символов**, в конце которого стоит невидимый ноль-байт `'\0'` (признак
"строка кончилась").

```c
#include <stdio.h>
#include <string.h>
int main(void) {
    char name[] = "flag";          // массив из 'f','l','a','g','\0'
    printf("%s\n", name);              // %s печатает до '\0' -> flag
    printf("длина: %zu\n", strlen(name));   // -> длина: 4
    printf("name[0] = %c\n", name[0]);      // элемент по индексу -> f
    return 0;
}
```

💡 Индексация с нуля, как в Python: `name[0]` - первый символ. `char buf[8]` - место ровно на 8
символов (меньше, чем кажется: один байт съедает `'\0'`). Запомни это к теме pwn.

Массив чисел читается так же:

```c
#include <stdio.h>
int main(void) {
    char target[] = {0x66, 0x6c, 0x61, 0x67};   // эталон в виде кодов
    for (int i = 0; i < 4; i++) printf("%c", target[i]);   // напечатать как символы
    printf("\n");                                           // -> flag
    return 0;
}
```

🔺 Такой `target[]` с кодами - типичная "проверка пароля" в реверсе: программа сравнивает твой ввод
с этим массивом. Как это обращать - в `08-reverse/medium.md`, п. 8.5.

## 2. Указатели: `&` и `*`

Указатель - это переменная, которая хранит **адрес** другой переменной. Пугает только из-за значков:

- `&x` - "адрес переменной `x`" (где она лежит в памяти);
- `*p` - "значение по адресу, который лежит в `p`" (разыменование).

```c
#include <stdio.h>
int main(void) {
    int x = 42;
    int *p = &x;         // p хранит адрес x. Тип "int *" = "указатель на int"
    printf("%d\n", *p);      // * = значение по адресу -> 42
    *p = 100;                // пишем по адресу -> меняем сам x
    printf("%d\n", x);       // -> 100
    return 0;
}
```

💡 Читать так: `*` и `&` - противоположности. `&` берёт адрес, `*` ходит по адресу обратно к
значению. Указатели нужны, потому что через них функция может **менять** переданную ей переменную,
и потому что строки/массивы передаются именно адресом начала.

⚠️ В декомпиляторе указатели видно по звёздочке и по именам вроде `param_1`, `puVar3`. Не пугайся:
если видишь `*(something + i)` - это просто "`something[i]`", обращение к элементу.

## 3. Структуры: несколько полей рядом

`struct` - это несколько переменных, лежащих в памяти **вплотную** друг к другу под одним именем.

```c
#include <stdio.h>
struct User {
    char name[8];      // 8 байт под имя
    int  is_admin;     // сразу за ними - флаг прав
};
int main(void) {
    struct User u = {"guest", 0};
    printf("%s admin=%d\n", u.name, u.is_admin);   // -> guest admin=0
    return 0;
}
```

🔺 "Лежат вплотную" - ключевая мысль для pwn: если переполнить `name`, лишние байты попадут в
`is_admin` (см. `09-pwn`). А в реверсе поля структуры в Ghidra видно как `*(int *)(ptr + 8)` -
"число по смещению 8 от начала".

## 4. Чтение логики: if, циклы, функции

Управляющие конструкции почти как в Python, только со скобками `{ }` и `;` в конце строк.

```c
#include <stdio.h>
int check(int code) {          // функция: принимает число, возвращает число
    if (code == 1337) return 1;    // == сравнение (как в Python)
    else return 0;
}
int main(void) {
    for (int i = 0; i < 3; i++) {      // цикл: i = 0,1,2
        printf("%d ", i);
    }
    printf("\n");                       // -> 0 1 2
    printf("check(1337) = %d\n", check(1337));   // -> check(1337) = 1
    return 0;
}
```

Как читать `for (int i = 0; i < 3; i++)`: "начни с `i=0`; пока `i < 3`; после каждого прохода `i++`
(увеличь на 1)". Это тот же `for i in range(3)` из Python.

Сравнения и логика: `==` равно, `!=` не равно, `&&` и, `||` или, `!` не. Побитовые (нужны в крипте и
реверсе): `^` XOR, `&` И, `|` ИЛИ, `<<`/`>>` сдвиги - те же, что в Python (`04-crypto`).

💡 На реверсе твоя цель - найти `if`, где решается "правильно/неправильно", и понять, **что с чем
сравнивают**. Всё остальное можно пролистать.

## 5. Полезные флаги gcc

```bash
gcc -o prog prog.c            # обычная сборка
gcc -Wall -o prog prog.c      # -Wall = показать предупреждения (помогает найти ошибку)
gcc -g -o prog prog.c         # -g = добавить отладочную информацию (удобнее в gdb, см. 08-reverse)
gcc -static -o prog prog.c    # вшить библиотеки внутрь (бинарь больше, но самодостаточный)
```

🎯 **Тренировка.** Собери программу с массивом `char s[] = "test";` и напечатай каждый символ по
индексу в цикле `for`. Потом добавь функцию `int first(char *s) { return s[0]; }` и выведи её
результат - так ты свяжешь строки, массивы, указатели и функции в одном месте.

🎯 **Тренировка.** Напиши программу, которая хранит `char target[] = {0x66,0x6c,0x61,0x67};` и
печатает его как строку. Затем, "глазами реверсера", не запуская, определи по кодам, что там за
слово. Это ровно то, что ждёт в `08-reverse`.
