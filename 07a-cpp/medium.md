# C/C++ (medium). Читаем чужой код: массивы, строки, указатели

Здесь учимся **читать** C: массивы, указатели и циклы постоянно встречаются в Ghidra.
Примеры можно собрать: `gcc -o prog prog.c && ./prog`.

---

## 1. Массивы и строки - это `char[]`

Строка в C - **массив символов** с нулевым байтом `'\0'` в конце.

```c
#include <stdio.h>
#include <string.h>
int main(void) {
    char name[] = "flag";          // массив из 'f','l','a','g','\0'
    printf("%s\n", name);              // %s печатает до '\0' -> flag
    printf("длина: %zu\n", strlen(name));   // -> длина: 4
    printf("name[0] = %c\n", name[0]);      // элемент по индексу -> f
    return 0;
}
```

Индексы начинаются с нуля: `name[0]` - первый символ. В `char buf[8]` помещается строка
из **7 символов и `'\0'`**. Это ограничение важно для pwn.

Массив чисел читается так же:

```c
#include <stdio.h>
int main(void) {
    char target[] = {0x66, 0x6c, 0x61, 0x67};   // эталон в виде кодов
    for (int i = 0; i < 4; i++) printf("%c", target[i]);   // напечатать как символы
    printf("\n");                                           // -> flag
    return 0;
}
```

🔺 Такой `target[]` с кодами - типичная "проверка пароля" в реверсе: программа сравнивает твой ввод
с этим массивом. Как это обращать - в `08-reverse/medium.md`, п. 8.5.

## 2. Указатели: `&` и `*`

Указатель хранит **адрес в памяти**:

- `&x` - адрес переменной `x`;
- `*p` - значение по адресу из `p` (разыменование).

```c
#include <stdio.h>
int main(void) {
    int x = 42;
    int *p = &x;         // p хранит адрес x. Тип "int *" = "указатель на int"
    printf("%d\n", *p);      // * = значение по адресу -> 42
    *p = 100;                // пишем по адресу -> меняем сам x
    printf("%d\n", x);       // -> 100
    return 0;
}
```

Через указатель функция может **менять** чужую переменную. Массивы и строки тоже передают
через адрес начала.

💡 В декомпиляторе типы указателей содержат `*`, а имена бывают вроде `param_1`, `puVar3`.
Запись `*(something + i)` равнозначна `something[i]` - это обращение к элементу.

## 3. Структуры: несколько полей рядом

`struct` объединяет несколько полей в памяти. Между ними возможны отступы для выравнивания.

```c
#include <stdio.h>
struct User {
    char name[8];      // 8 байт под имя
    int  is_admin;     // сразу за ними - флаг прав
};
int main(void) {
    struct User u = {"guest", 0};
    printf("%s admin=%d\n", u.name, u.is_admin);   // -> guest admin=0
    return 0;
}
```

🔺 Выход за границы `name` может затереть `is_admin` (см. `09-pwn`). В Ghidra поле по смещению
8 байт от начала структуры может выглядеть как `*(int *)(ptr + 8)`.

## 4. Чтение логики: if, циклы, функции

Управляющие конструкции почти как в Python, только со скобками `{ }` и `;` в конце строк.

```c
#include <stdio.h>
int check(int code) {          // функция: принимает число, возвращает число
    if (code == 1337) return 1;    // == сравнение (как в Python)
    else return 0;
}
int main(void) {
    for (int i = 0; i < 3; i++) {      // цикл: i = 0,1,2
        printf("%d ", i);
    }
    printf("\n");                       // -> 0 1 2
    printf("check(1337) = %d\n", check(1337));   // -> check(1337) = 1
    return 0;
}
```

Как читать `for (int i = 0; i < 3; i++)`: "начни с `i=0`; пока `i < 3`; после каждого прохода `i++`
(увеличь на 1)". Это тот же `for i in range(3)` из Python.

Сравнения и логика: `==` равно, `!=` не равно, `&&` и, `||` или, `!` не. Побитовые (нужны в крипте и
реверсе): `^` XOR, `&` И, `|` ИЛИ, `<<`/`>>` сдвиги - те же, что в Python (`04-crypto`).

На реверсе ищи `if`, от которого зависит успех, и разбирай, **что с чем сравнивают**.

## 5. Полезные флаги gcc

```bash
gcc -o prog prog.c            # обычная сборка
gcc -Wall -o prog prog.c      # -Wall = показать предупреждения (помогает найти ошибку)
gcc -g -o prog prog.c         # -g = добавить отладочную информацию (удобнее в gdb, см. 08-reverse)
gcc -static -o prog prog.c    # вшить библиотеки внутрь (бинарь больше, но самодостаточный)
```

🎯 **Тренировка.** Собери программу с массивом `char s[] = "test";` и напечатай каждый символ по
индексу в цикле `for`. Потом добавь функцию `int first(char *s) { return s[0]; }` и выведи её
результат - так ты свяжешь строки, массивы, указатели и функции в одном месте.

🎯 **Тренировка.** Выведи `char target[] = {0x66,0x6c,0x61,0x67};` посимвольно, как в примере выше
(для `%s` нужен завершающий `'\0'`). До запуска определи слово по кодам - так же, как в `08-reverse`.
