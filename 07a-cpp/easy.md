# C/C++ (easy). Зачем это нужно и как собрать

Python ты уже знаешь, но реверс и pwn почти всегда про **C/C++**. Учить язык целиком не надо:
достаточно **читать** чужой C (чтобы понимать программу в Ghidra) и уметь **собрать и запустить**
небольшую программу. Эта глава - подводка к `08-reverse` и `09-pwn`.

---

## 1. Компилируемый язык - чем отличается от Python

Python запускается сразу: `python3 task.py`. C так не умеет: исходник (`.c`) сначала
**компилируют** в машинный код, и только потом программу можно запустить.

| | Python | C |
|---|---|---|
| Файл с кодом | `.py` | `.c` (C) или `.cpp` (C++) |
| Запуск | `python3 task.py` | сначала собрать, потом `./task` |
| Что дают на реверсе | редко (читаемый текст) | **часто** (готовый бинарник без текста) |

💡 Поэтому реверс C сложнее: исходника нет, есть только скомпилированная программа. Декомпилятор
(Ghidra) переводит её обратно в **похожий на C** псевдокод - и его надо уметь читать.

---

## 2. Собрать и запустить

Компилятор C называется `gcc`, для C++ - `g++`. Оба есть в образе.

```bash
gcc -o prog prog.c     # собрать prog.c -> программа с именем prog
./prog                 # запустить
```

Или одной строкой:

```bash
gcc -o prog prog.c && ./prog    # собрать и, если без ошибок, сразу запустить
```

⚠️ Забыл `./` перед именем? Терминал не найдёт программу. Запускать - именно `./prog`, а не `prog`.

## 3. Самая маленькая программа

```c
#include <stdio.h>           // подключить функции ввода-вывода (printf и т.п.)

int main(void) {             // main - откуда программа начинает работу
    printf("flag{42}\n");    // напечатать строку, \n - перевод строки
    return 0;                // 0 = завершились успешно
}
```

Собери и запусти:

```bash
gcc -o prog prog.c && ./prog     # -> flag{42}
```

Скелет `#include`, `int main(void) { ... return 0; }` будет почти в каждой программе.

## 4. Числа и символы

В C у каждой переменной заранее указан **тип**. Два главных:

```c
#include <stdio.h>
int main(void) {
    int x = 40;              // int - целое число
    int y = 2;
    printf("flag{%d}\n", x + y);   // %d = "подставь сюда целое" -> flag{42}
    return 0;
}
```

```c
#include <stdio.h>
int main(void) {
    char c = 'A';            // char - один символ, по сути число (код 'A' = 65)
    printf("%c = %d\n", c, c);     // %c = символ, %d = число -> A = 65
    printf("%c\n", c + 1);         // с символом можно считать -> B
    return 0;
}
```

💡 Это та же идея, что `ord`/`chr` в Python (`03-python`): **символ - это число**. На реверсе часто
сравнивают `char` с числом (`if (c == 0x66)`) - это сравнение с кодом буквы `'f'`.

Главные значки формата в `printf`: `%d` - целое, `%c` - символ, `%s` - строка, `%x` - hex.

🎯 **Тренировка.** Собери программу, которая печатает `flag{...}`, где внутри - сумма двух чисел.
Поменяй `int` на свои числа, пересобери (`gcc -o prog prog.c`) и запусти. Потом выведи символ по
коду: `printf("%c\n", 102);` - должно получиться `f`.
