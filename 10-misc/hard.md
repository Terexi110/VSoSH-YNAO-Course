## 1. Менее очевидные кодировки

```python
import base64, codecs
base64.b85decode("...")              # Base85 (плотнее Base64)
base64.b32decode("...")              # Base32 (A-Z,2-7)
codecs.decode("uryyb", "rot13")      # ROT13
bytes.fromhex("...")                 # hex
# uuencode / xxencode - старые; ищи "begin 644" в начале
```
`Base58` не содержит `0,O,I,l`, часто встречается в криптокошельках и ключах; для декодирования
нужен отдельный модуль. Реже бывают `Base91`/`Base92`. Ищи «base» и признаки алфавита.

## 2. Эзотерические языки

Распознавай по виду:

| Как выглядит | Язык |
|---|---|
| `+++++[>++++<-]>.` | **Brainfuck** |
| `Ook. Ook? Ook!` | **Ook!** (тот же BF) |
| `╔╗ ░▒▓` / пробелы и табы | **Whitespace** / Malbolge и др. |
| слова `right left pick` | эзотерика на словах |

Мини-интерпретатор Brainfuck (достаточно для CTF):

```python
def brainfuck(code):
    tape = [0]*30000; p = 0; out = []; ip = 0
    while ip < len(code):
        c = code[ip]
        if   c == '>': p += 1
        elif c == '<': p -= 1
        elif c == '+': tape[p] = (tape[p]+1) % 256
        elif c == '-': tape[p] = (tape[p]-1) % 256
        elif c == '.': out.append(tape[p])
        elif c == '[' and tape[p] == 0:          # пропустить цикл
            d = 1
            while d: ip += 1; d += (code[ip]=='[') - (code[ip]==']')
        elif c == ']' and tape[p] != 0:          # вернуться в начало цикла
            d = 1
            while d: ip -= 1; d += (code[ip]==']') - (code[ip]=='[')
        ip += 1
    return bytes(out)

print(brainfuck("+"*65 + "."))     # выведет b'A' (код 65)
```

## 3. "Матрёшки": авто-декодер вложенных кодировок

Флаг могут закодировать в несколько слоёв: Base64, затем hex и так далее.
Определяй формат каждого слоя; для повторного Base64 подойдёт цикл:

```python
import base64
cur = open("data.txt","rb").read().strip()
for _ in range(50):                               # ограничим число слоёв
    try:
        dec = base64.b64decode(cur, validate=True)
    except Exception:
        break
    if not dec or dec == cur: break
    cur = dec
    if b"flag{" in cur:
        print(cur); break
print(cur)
```
Вложенные архивы тоже распаковывай циклом, пока внутри остаётся архив.

## 4. Запароленные архивы: перебор

```bash
zip2john secret.zip > hash.txt               # вытащить хеш пароля (есть rar2john / 7z2john)
john --wordlist=words.txt hash.txt           # подобрать по словарю; john --show hash.txt - результат
7z x secret.7z                                # 7z спросит пароль
unzip -z secret.zip                           # показать комментарий архива (там бывает подсказка)
```
Без `zip2john`/`john` перебирай ZIP через `zipfile` (см. `medium.md`, п. 10.1).
💡 До перебора проверь метаданные другого файла, название и комментарий архива: там бывает пароль.

## 5. QR и штрихкоды (сложные случаи)

Читай код установленным декодером или телефоном, если правила тура разрешают:

```bash
zbarimg код.png                               # если есть; берёт и Data Matrix / Aztec
```
Для повреждённого QR попробуй инверсию цветов, восстановление позиционных квадратов в трёх углах
и коррекцию контраста, затем сканируй снова. Есть догадка о содержимом — создай QR командой
`qr "догадка"` (пакет python3-qrcode) и сравни с оригиналом.
