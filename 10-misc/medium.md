# Глава 10. Misc - разное

**Misc** — архивы, кодировки, системы счисления, QR-коды и необычные форматы вне других категорий.

## 10.1. Архивы

```bash
unzip archive.zip                 # распаковать zip
tar -xf archive.tar               # распаковать tar (-x extract, -f file)
tar -xzf archive.tar.gz           # tar.gz (-z = gzip)
7z x archive.7z                   # 7-zip (универсально; умеет и zip, и rar)
file archive                      # если расширение непонятное - определить тип
```

**Запароленный архив.** Извлеки данные для подбора через `zip2john`/`rar2john`/`7z2john`,
затем запусти **john** из учебного образа со словарём:

```bash
zip2john archive.zip > hash.txt               # извлечь хеш пароля из zip
john hash.txt --wordlist=words.txt            # подобрать по словарю
john hash.txt --show                          # показать найденный пароль
7z x archive.7z -pПАРОЛЬ                       # если пароль уже известен
```

Перебор ZIP на Python без внешних утилит (офлайн, через `zipfile`):

```python
import zipfile

words = ["admin", "password", "123456", "s3cret"]   # словарь или строки из задачи
z = zipfile.ZipFile("archive.zip")
for w in words:
    try:
        z.extractall(pwd=w.encode())      # пробуем пароль
        print("пароль:", w); break        # не упало -> пароль верный, файлы распакованы
    except (RuntimeError, zipfile.BadZipFile):
        continue                           # неверный -> следующий
```

💡 Сначала поищи пароль в описании, метаданных другого файла и комментарии архива
(`unzip -z archive.zip`). Вложенные архивы-«матрёшки» распаковывай по очереди; это можно
автоматизировать циклом.

⚠️ **Битый архив.** Если `file` распознаёт ZIP, а `unzip` выдаёт ошибку, проверь заголовки:
их могли намеренно повредить. Попробуй `zip -FF broken.zip --out fixed.zip` или разбери структуру в hex.

## 10.2. Кодировки и системы счисления

Узнай представление данных по виду и примени преобразование из глав 3–4:

| Что видишь | Что это | Как перевести |
|---|---|---|
| `01001000 01101001` | двоичный (binary) | `int('01001000', 2)` -> код символа -> `chr()` |
| `72 105` или `0x48 0x69` | десятичные/hex коды | `chr(72)`, `chr(0x48)` |
| `.... .. .- --` | азбука Морзе | таблица Морзе (точки/тире) |
| `ЗmxhZw==` | Base64 | `base64.b64decode` |
| текст из `A-Z2-7` | Base32 | `base64.b32decode` |

**Двоичный -> текст** (частый misc):

```python
bits = "01100110 01101100 01100001 01100111"
print("".join(chr(int(b, 2)) for b in bits.split()))   # -> flag
```

**Перевод систем счисления** прямо в Python:

```python
>>> int("1010", 2)     # двоичное
10
>>> int("ff", 16)      # hex
255
>>> int("777", 8)      # восьмеричное
511
>>> bin(10)
'0b1010'
>>> hex(255)
'0xff'
```

💡 **Морзе** узнают по точкам и тире, **Брайль** — по шеститочечным ячейкам. Для частых букв
Морзе таблицу можно восстановить по памяти; для декодирования — собрать словарь в Python.

## 10.3. QR-коды и штрихкоды

**Прочитать QR.** Камера или сканер телефона работают офлайн, но на туре сначала проверь правила.
На компьютере используй `zbarimg` или Python-модуль `pyzbar`, если они установлены:

```bash
zbarimg qr.png            # если zbarimg есть - покажет содержимое QR/штрихкода
```

**Создать QR.** В учебном образе есть `qr` (пакет python3-qrcode) и модуль `qrcode`.
Они пригодятся для кодирования строки или сравнения догадки с повреждённым QR:

```bash
qr "flag{example}"                      # нарисовать QR прямо в терминале (ASCII)
qr --output=code.png "flag{example}"    # сохранить в PNG (или .svg)
```

```python
import qrcode
img = qrcode.make("текст или ссылка")   # создать QR-картинку
img.save("qr.png")
# из того же набора есть модуль pyqrcode (умеет PNG/SVG/текст)
```

**Битый QR.** Для закрашенного, инвертированного или обрезанного кода попробуй в редакторе
инверсию цветов, восстановление трёх позиционных квадратов по углам и повышение контраста.
Повтори сканирование. Есть догадка о содержимом — создай QR через `qr` и сравни с оригиналом.
