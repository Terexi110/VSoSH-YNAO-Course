## 10.1. Архивы

```bash
unzip archive.zip                 # распаковать zip
tar -xf archive.tar               # распаковать tar (-x extract, -f file)
tar -xzf archive.tar.gz           # tar.gz (-z = gzip)
7z x archive.7z                   # 7-zip (универсально; умеет и zip, и rar)
file archive                      # если расширение непонятное - определить тип
```

**Запароленный архив.** Пароль перебирают по словарю. В образе есть **john**: сначала вытащи из
архива "хеш" помощником (`zip2john`/`rar2john`/`7z2john`), потом подбери словарём:

```bash
zip2john archive.zip > hash.txt               # извлечь хеш пароля из zip
john hash.txt --wordlist=words.txt            # подобрать по словарю
john hash.txt --show                          # показать найденный пароль
7z x archive.7z -pПАРОЛЬ                       # если пароль уже известен
```

Тот же перебор **без внешних утилит** - на чистом Python (модуль `zipfile`, работает офлайн):

```python
import zipfile

words = ["admin", "password", "123456", "s3cret"]   # словарь или строки из задачи
z = zipfile.ZipFile("archive.zip")
for w in words:
    try:
        z.extractall(pwd=w.encode())      # пробуем пароль
        print("пароль:", w); break        # не упало -> пароль верный, файлы распакованы
    except (RuntimeError, zipfile.BadZipFile):
        continue                           # неверный -> следующий
```

💡 Пароль часто лежит рядом: в описании, в метаданных другого файла, в комментарии к архиву
(`unzip -z archive.zip` показывает комментарий). Матрёшка из вложенных архивов - тоже классика:
распаковываешь, внутри снова архив, и так много раз (можно автоматизировать циклом).

⚠️ **Битый архив.** Если `unzip` ругается, но файл точно архив (`file` подтверждает) - zip мог быть
намеренно "подпорчен" (неверный заголовок). Чинится `zip -FF broken.zip --out fixed.zip` или
анализом структуры в hex.

## 10.2. Кодировки и системы счисления

Любые "странные числа/символы" - прогоняй через знакомые преобразования (глава 3-4):

| Что видишь | Что это | Как перевести |
|---|---|---|
| `01001000 01101001` | двоичный (binary) | `int('01001000', 2)` -> код символа -> `chr()` |
| `72 105` или `0x48 0x69` | десятичные/hex коды | `chr(72)`, `chr(0x48)` |
| `.... .. .- --` | азбука Морзе | таблица Морзе (точки/тире) |
| `ЗmxhZw==` | Base64 | `base64.b64decode` |
| текст из `A-Z2-7` | Base32 | `base64.b32decode` |

**Двоичный -> текст** (частый misc):

```python
bits = "01100110 01101100 01100001 01100111"
print("".join(chr(int(b, 2)) for b in bits.split()))   # -> flag
```

**Перевод систем счисления** прямо в Python:

```python
>>> int("1010", 2)     # двоичное
10
>>> int("ff", 16)      # hex
255
>>> int("777", 8)      # восьмеричное
511
>>> bin(10)
'0b1010'
>>> hex(255)
'0xff'
```

💡 **Морзе** и **азбуку Брайля** узнают по виду (точки/тире; шеститочечные ячейки). Таблицу Морзе
можно восстановить по памяти для частых букв или собрать словарём в Python.

## 10.3. QR-коды и штрихкоды

**Прочитать готовый QR.** Надёжнее всего навести телефон: камера или сканер читает QR мгновенно и
офлайн. На выданной машине декодер (`zbarimg`, python `pyzbar`) может быть не установлен, поэтому
телефон - первый выбор.

```bash
zbarimg qr.png            # если zbarimg есть - покажет содержимое QR/штрихкода
```

**Создать QR.** Это умеет гарантированно доступная утилита `qr` (пакет python3-qrcode) и одноимённый
модуль Python. Нужно, когда задача просит *закодировать* строку в QR или когда проверяешь догадку о
"битом" коде - рисуешь свой и сравниваешь:

```bash
qr "flag{example}"                      # нарисовать QR прямо в терминале (ASCII)
qr --output=code.png "flag{example}"    # сохранить в PNG (или .svg)
```

```python
import qrcode
img = qrcode.make("текст или ссылка")   # создать QR-картинку
img.save("qr.png")
# из того же набора есть модуль pyqrcode (умеет PNG/SVG/текст)
```

**Битый QR.** Закрашен, инвертирован или обрезан - сначала почини в редакторе: инвертируй цвета,
дорисуй три позиционных квадрата по углам, подними контраст - и сканируй телефоном. Угадал
содержимое - сгенерируй свой QR утилитой `qr` и сравни рисунок с оригиналом.

## 10.4. Общий принцип Misc

Misc проверяет не знание, а сообразительность. Алгоритм:
1. `file` - что это вообще.
2. `strings | grep flag` - не лежит ли открыто.
3. Опознать "язык" данных (кодировка, система счисления, формат) по виду.
4. Прогнать через Python/утилиту.

🎯 **Тренировка 26.** Возьми слово `flag`, переведи его в двоичный вид (`' '.join(f'{ord(c):08b}' for c in 'flag')`),
а потом восстанови обратно скриптом из п. 10.2. Сделай то же через hex-коды. Так "странные числа" в
задачах перестанут пугать.

> Misc берётся не знанием, а насмотренностью: архив вскрыть (в том числе запароленный или матрёшку),
> странные числа перевести, QR отсканировать. Застрял - вернись к общему алгоритму из конца главы.
> Остались приложения: весь курс там сжат в шпаргалки для быстрого повторения.
