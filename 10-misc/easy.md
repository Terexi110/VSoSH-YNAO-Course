# Глава 10 (easy). Misc - самая база

Misc - это "разное": архивы, странные кодировки, QR-коды. Решается быстро, если знаешь приём.

## Архивы

```bash
unzip файл.zip            # распаковать zip
tar -xf файл.tar          # распаковать tar
file файл                 # если расширение непонятное - узнать тип
```

## Двоичный код -> текст

Если видишь нули и единицы группами по 8 - это буквы:

```python
bits = "01100110 01101100 01100001 01100111"
print("".join(chr(int(b, 2)) for b in bits.split()))   # -> flag
```

## Hex-коды -> текст

```python
print(bytes.fromhex("666c6167"))      # -> b'flag'
```

## QR-код

Если дали картинку с QR - проще всего навести телефон, камера читает его сразу. На машине, если
установлен декодер:

```bash
zbarimg qr.png            # покажет, что зашито в QR (если zbarimg есть)
```

А создать свой QR можно утилитой `qr "текст"` - она точно есть в образе.

🎯 **Тренировка.** Переведи `"01100110 01101100 01100001 01100111"` в текст скриптом выше. Распакуй
любой zip командой `unzip`.
