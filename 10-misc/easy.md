# Глава 10 (easy). Misc: основы

**Misc** — задачи вне остальных категорий: архивы, кодировки, QR-коды.

## Архивы

```bash
unzip файл.zip            # распаковать zip
tar -xf файл.tar          # распаковать tar
file файл                 # если расширение непонятное - узнать тип
```

## Двоичный и hex-код → текст

Нули и единицы группами по 8 могут быть кодами символов:

```python
bits = "01100110 01101100 01100001 01100111"
print("".join(chr(int(b, 2)) for b in bits.split()))   # -> flag
```

Для hex используй `bytes.fromhex`:

```python
print(bytes.fromhex("666c6167"))      # -> b'flag'
```

## QR-код

Прочитай QR камерой телефона, если правила тура это разрешают, или установленным декодером:

```bash
zbarimg qr.png            # покажет, что зашито в QR (если zbarimg есть)
```

Создать QR можно утилитой `qr "текст"` из учебного образа.

🎯 **Тренировка.** Декодируй `"01100110 01101100 01100001 01100111"` скриптом выше
и распакуй любой zip командой `unzip`.
