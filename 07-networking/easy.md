# Глава 7 (easy). Сети - самая база

Некоторые задачи - это не файл, а **сервис**: дан адрес вида `IP ПОРТ`, к нему надо подключиться.

## Подключиться к серверу

```bash
nc 10.0.0.5 31337
```

`nc` (netcat) открывает "трубу" к серверу. Сервер что-то пишет - ты читаешь прямо в терминале.
Если он задаёт вопрос - печатаешь ответ и жмёшь Enter.

## Что это за числа

- **IP** (`10.0.0.5`) - адрес компьютера в сети.
- **ПОРТ** (`31337`) - номер "двери" на нём.

## Пример

```
$ nc 10.0.0.5 31337
Назови пароль:
letmein
Верно! flag{...}
```

🎯 **Тренировка.** В одном окне запусти "сервер" (`nc -lvp 9999`; если `nc` ругается на `-p` -
напиши `nc -lv 9999`), в другом подключись (`nc 127.0.0.1 9999`) и попиши - текст появляется на
другой стороне.
