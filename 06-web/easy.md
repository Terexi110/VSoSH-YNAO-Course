# Глава 6 (easy). Web - самая база

Веб-задача: дан сайт, надо найти на нём флаг или уязвимость. Главный инструмент - браузер.

## 1. Смотри исходный код страницы

Нажми **Ctrl+U** (просмотр исходного кода) - флаг часто спрятан прямо там, в комментарии:

```html
<!-- flag{its_in_the_source} -->
```

💡 Флаг часто делят на части между HTML, `style.css` и `script.js`. В окне Ctrl+U кликай по синим
ссылкам на `.css`/`.js` в начале кода - остальные куски прячут там.

## 2. Открой панель разработчика - F12

Там вкладки:
- **Elements** - HTML-код страницы;
- **Console** - сообщения (иногда флаг выводят туда);
- **Application -> Cookies** (в Firefox вкладки называются **Инспектор** и **Хранилище -> Куки**) - куки (кто ты для сайта).

## 3. Проверь robots.txt

Этот файл перечисляет "скрытые" страницы. Открой в браузере:

```
http://адрес-сайта/robots.txt
```

То, что просили не показывать поисковикам, часто и есть цель.

## 4. curl - сайт из терминала

```bash
curl http://сайт/страница        # получить страницу текстом
```

🎯 **Тренировка.** Открой любой сайт, нажми Ctrl+U и поищи `flag` (Ctrl+F). Потом зайди на
`/robots.txt` этого сайта.
