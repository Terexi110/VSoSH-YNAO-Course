# Глава 3. Python как швейцарский нож

На CTF Python заменяет и калькулятор, и онлайн-конвертеры. Большинство крипто- и misc-задач - это
скрипт в 5-10 строк. Эта глава про то, как пользоваться Python, когда под рукой **нет ни интернета,
ни документации** - только сам Python.

## 3.1. Два режима: интерактивный и скрипт

**Интерактивный** (для быстрых проб и как калькулятор):

```bash
$ python3
>>> 1337 * 42
56154
>>> hex(255)          # число -> hex
'0xff'
>>> int('ff', 16)     # hex-строка -> число
255
>>> pow(7, 20, 13)    # 7^20 mod 13 - быстро и без переполнений
9
>>> pow(17, -1, 3120) # обратный по модулю (d в RSA) - без сторонних библиотек!
2753
>>> exit()            # выйти (или Ctrl+D)
```

**Скрипт** (когда логика длиннее пары строк) - сохрани в файл `solve.py` и запусти:

```bash
$ python3 solve.py
```

⚠️ Запускай скрипты решения **из отдельной папки**, не из той, куда скачал файлы задачи. Если
обязательно рядом - используй изолированный режим:

```bash
python3 -I solve.py    # -I = не подхватывать модули из текущей папки (чтобы свой файл
                       #      base64.py или math.py не сломал импорт стандартных библиотек)
```

## 3.2. Как вспомнить синтаксис офлайн - `dir()` и `help()`

Нет интернета, забыл функцию? Спроси у самого Python:

```python
>>> import base64
>>> dir(base64)              # показать всё, что умеет модуль
['b16decode', 'b16encode', 'b32decode', 'b32encode', 'b64decode', 'b64encode', ...]

>>> help(base64.b64decode)   # подробная справка (выход - q)

>>> dir("")                  # что умеют строки
[..., 'encode', 'find', 'replace', 'split', 'upper', ...]

>>> dir(b"")                 # что умеют байты
[..., 'decode', 'fromhex', 'hex', ...]
```

💡 `dir(объект)` = "покажи все методы", `help(что-то)` = "объясни подробно". Этого хватает, чтобы
работать совсем без документации. Привыкни пользоваться - на туре это спасает.

🎯 **Тренировка 5.** В интерактивном Python выполни `import base64; dir(base64)` и найди глазами
функции для Base32 и Base16. Потом `help(base64.b32decode)` - прочитай, что она принимает.

## 3.3. Строки vs байты - ключевое различие

Здесь новички путаются чаще всего. Запомни:

| Тип | Как выглядит | Что это |
|---|---|---|
| `str` (строка) | `"привет"` | **текст**, человеческие символы |
| `bytes` (байты) | `b"\x89PNG"` | **сырые байты**, то, что реально лежит в файле |

На CTF данные почти всегда - **байты**, которые надо превратить в текст (или наоборот).

```python
>>> "ABC".encode()       # строка -> байты
b'ABC'
>>> b'ABC'.decode()      # байты -> строка
'ABC'
>>> bytes([102, 108, 97, 103])   # список чисел -> байты
b'flag'
```

⚠️ Нельзя складывать `str + bytes`. Ошибка `can't concat str to bytes` означает, что где-то
перепутал типы - добавь `.encode()` или `.decode()`.

💡 После XOR или вытаскивания сырых байтов обычный `.decode()` часто падает с `UnicodeDecodeError`
на первом же "кривом" байте. Два спасения:
```python
b"flag\xff".decode(errors="ignore")   # пропустить битые байты -> 'flag'
b"flag\xff".decode("latin1")          # latin1: любой байт 0..255 переводит один-в-один
```

## 3.4. Работа с файлами: `rb` против `r`

```python
# Текстовый режим 'r' - для обычного текста
with open("cipher.txt", "r", encoding="utf-8") as f:
    text = f.read()        # получишь str

# Бинарный режим 'rb' - для картинок, бинарников, ЛЮБЫХ сырых данных
with open("file.bin", "rb") as f:
    data = f.read()        # получишь bytes
```

💡 Правило: **текст - `"r"`, всё остальное - `"rb"`**. Сомневаешься - бери `"rb"`, с сырыми
байтами ошибиться сложнее. Запись: `open(..., "wb")` и `f.write(data)`.

## 3.5. Hex и Base64 - перевод туда-обратно

**Hex (шестнадцатеричное представление байтов):**

```python
>>> bytes.fromhex("666c6167")   # hex-строка -> байты
b'flag'
>>> b'flag'.hex()               # байты -> hex-строка
'666c6167'
>>> int("0xf", 16)              # hex-число -> десятичное число
15
```

**Base64** (очень частая кодировка; признак - буквы/цифры и `+/=`, напр. `ZmxhZw==`):

```python
>>> import base64
>>> base64.b64decode("ZmxhZw==")    # base64 -> байты
b'flag'
>>> base64.b64encode(b"flag")       # байты -> base64
b'ZmxhZw=='
```

💡 Те же переводы прямо из терминала, без скрипта:

```bash
echo 'ZmxhZw==' | base64 -d        # декодировать base64
echo -n 'flag'  | base64           # закодировать
echo -n '666c6167' | xxd -r -p     # hex -> байты
echo -n 'flag' | xxd -p            # байты -> hex
```

## 3.6. `chr()` и `ord()` - числа <-> символы

Фундамент почти всех шифров: каждый символ - это число (его код).

```python
>>> ord('A')     # символ -> код
65
>>> chr(65)      # код -> символ
'A'
```

Опорные коды ASCII: `'0'`-`'9'` -> 48-57, `'A'`-`'Z'` -> 65-90, `'a'`-`'z'` -> 97-122.

```python
>>> "".join(chr(c) for c in [102, 108, 97, 103])
'flag'
```

## 3.7. XOR - побитовое исключающее ИЛИ

XOR (`^`) - главная операция симметричной крипты. Свойство: `A ^ K ^ K = A` (наложил ключ дважды -
вернулся к исходнику). Поэтому зашифровать и расшифровать XOR'ом - **одно и то же действие**.

```python
>>> 5 ^ 3
6
>>> 65 ^ 42 ^ 42   # наложили ключ 42 дважды - получили обратно 65
65
```

XOR двух последовательностей байтов (пригодится в главе крипты):

```python
a = b"flag"
b = b"\x10\x20\x30\x40"
xored = bytes(x ^ y for x, y in zip(a, b))   # zip - идём парами
```

🎯 **Тренировка 6.** В Python зашифруй слово XOR'ом с одним байтом и расшифруй обратно:
```python
c = bytes(ch ^ 0x42 for ch in b"secret")   # шифруем
print(bytes(ch ^ 0x42 for ch in c))         # тем же действием расшифровываем -> b'secret'
```

## 3.8. Шаблон "прочитать файл и посмотреть на байты"

С него начинается половина скриптов:

```python
with open("file.bin", "rb") as f:
    data = f.read()

print(len(data))        # сколько байт
print(data[:32])        # первые 32 байта
print(data[:32].hex())  # они же в hex
print(data[::-1])       # развернуть задом наперёд (частый трюк в простых тасках)
```

## 3.9. Что из стандартной библиотеки нужно на CTF

Всё это есть в любой установке Python - **интернет не требуется**:

| Модуль | Для чего | Ключевое |
|---|---|---|
| `base64` | кодировки Base64/32/16 | `b64decode`, `b32decode`, `b16decode` |
| `string` | готовые наборы символов | `ascii_lowercase`, `printable` |
| `collections` | частотный анализ | `Counter` |
| `itertools` | перебор, циклы | `product`, `cycle` |
| `hashlib` | хеши | `md5`, `sha256` |
| `socket` | общение с сервером (глава 7) | `socket`, `recv`, `sendall` |
| `math` | целая арифметика (RSA) | `isqrt`, `gcd` |

```python
>>> from collections import Counter
>>> Counter("aabbbc")      # посчитать символы
Counter({'b': 3, 'a': 2, 'c': 1})
```

> Этого набора хватит на всю крипту: два режима запуска, `dir`/`help` вместо гугла, байты против
> строк, hex и base64, `chr`/`ord` и XOR. Если что-то пока делаешь, подглядывая, - прогони тренировки
> ещё раз. Следующая глава как раз на этом и стоит.
