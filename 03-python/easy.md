# Глава 3 (easy). Python - самая база

На CTF Python заменяет калькулятор и конвертер. Запускается командой `python3`.

## Интерактивный режим (как калькулятор)

```bash
$ python3
>>> 2 + 2
4
>>> 2 ** 10          # степень
1024
>>> exit()           # или Ctrl + D - выйти
```

💡 `_` хранит прошлый результат: посчитал `2 ** 10` -> `1024`, следующей строкой пишешь `hex(_)` -> `'0x400'`.

💡 Если код уже лежит в файле (организаторы дали `task.py`) - запусти его из терминала: `python3 task.py`.

## Числа и системы счисления

```python
>>> hex(255)         # число -> hex
'0xff'
>>> int('ff', 16)    # hex -> число
255
>>> int('1010', 2)   # двоичное -> число
10
>>> bin(10)          # число -> двоичное
'0b1010'
```

## Символы и коды

```python
>>> ord('A')     # буква -> её код
65
>>> chr(65)      # код -> буква
'A'
```

## Раскодировать Base64 и hex (частое на CTF)

```python
>>> import base64
>>> base64.b64decode("ZmxhZw==")   # -> b'flag'
b'flag'
>>> bytes.fromhex("666c6167")       # hex -> байты -> b'flag'
b'flag'
```

> `b'flag'` - это "байты". Чтобы получить обычный текст, добавь `.decode()`:
> `base64.b64decode("ZmxhZw==").decode()` -> `'flag'`.

🎯 **Тренировка.** В `python3` посчитай `ord('f')`, потом `chr(102)`, потом
`base64.b64decode("aGVsbG8=")`. Выйди через `exit()`.
