# Глава 3 (easy). Основы Python

На CTF Python заменяет калькулятор и конвертер. Запускается командой `python3`.

## Расчёты и системы счисления

```bash
$ python3
>>> 2 + 2
4
>>> 2 ** 10          # степень
1024
>>> exit()           # или Ctrl + D - выйти
```

`_` хранит предыдущий результат: после `2 ** 10` вызов `hex(_)` вернёт `'0x400'`.
Код из файла запускают так: `python3 task.py`. Чужой скрипт сначала изучи.

```python
>>> hex(255)         # число -> hex
'0xff'
>>> int('ff', 16)    # hex -> число
255
>>> int('1010', 2)   # двоичное -> число
10
>>> bin(10)          # число -> двоичное
'0b1010'
```

## Символы и коды

```python
>>> ord('A')     # буква -> её код
65
>>> chr(65)      # код -> буква
'A'
```

## Раскодировать Base64 и hex (частое на CTF)

```python
>>> import base64
>>> base64.b64decode("ZmxhZw==")   # -> b'flag'
b'flag'
>>> bytes.fromhex("666c6167")       # hex -> байты -> b'flag'
b'flag'
```

`b'flag'` — байты. В текст их переводит `.decode()`:
`base64.b64decode("ZmxhZw==").decode()` → `'flag'`.

🎯 **Тренировка.** В `python3` посчитай `ord('f')`, потом `chr(102)`, потом
`base64.b64decode("aGVsbG8=")`. Выйди через `exit()`.

На **medium** — различие строк и байтов, файлы и XOR.
