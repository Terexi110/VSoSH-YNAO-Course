# Глава 2 (easy). Терминал Linux - самая база

Терминал - это окно, где команды пишут текстом. Здесь не нужно знать сотню команд - для старта хватит десяти.

## Главное отличие от Windows и горячие клавиши

В терминале привычные `Ctrl + C` и `Ctrl + V` заняты управлением процессами:
* **`Ctrl + Shift + C`** / **`Ctrl + Shift + V`** - скопировать / вставить текст в терминал.
* **`Ctrl + C`** - принудительно остановить зависшую программу.
* **`Tab`** - автодополнение! Начни писать имя файла (`cat sec`) и нажми `Tab` - терминал допишет `secret_file.txt` сам.
* **`^` / `v`** - листать ранее введённые команды.

⚠️ **Ловушка с `Ctrl + Z`:** в терминале это **НЕ "Отмена"**! `Ctrl + Z` усыпляет текущую программу и выбрасывает тебя обратно в командную строку. Если случайно нажал это в редакторе - напиши команду **`fg`** и нажми Enter, чтобы вернуться обратно.

### Текстовые редакторы: `nano` и `vim`
* **`nano файл.py`** - простой редактор (новичкам лучше использовать его):
  * Сохранить: `Ctrl + O` -> `Enter`.
  * Выйти: `Ctrl + X` (если спросит про сохранение: `Y` - да, `N` - нет).
  * Отменить действие: `Alt + U`.
* **`vim файл.py`** - мощный редактор с двумя режимами:
  * Чтобы начать печатать текст: нажми `i` (режим `INSERT`).
  * Чтобы выйти в режим команд: нажми `Esc`.
  * Сохранить и выйти: `Esc`, затем набрать `:wq` и `Enter` (`w` - write/записать, `q` - quit/выйти).
  * Выйти без сохранения: `Esc`, затем `:q!` и `Enter`.

## Где я и что рядом

```bash
pwd            # показать текущую папку
ls             # список файлов
ls -la         # список со всеми файлами (в т.ч. скрытыми) и подробностями
cd папка       # зайти в папку
cd ..          # выйти на уровень выше
```

## Посмотреть файл

```bash
file файл          # узнать настоящий тип файла (картинка? программа? архив?)
cat файл.txt       # вывести содержимое текстового файла на экран
chmod +x prog      # разрешить запуск программы (если file сказал, что это ELF)
./prog             # запустить программу из текущей папки
```

## Две самые полезные команды на CTF

```bash
strings файл          # вытащить читаемый текст из любого файла
grep слово файл       # найти строки со словом
```

Их обычно соединяют "трубой" `|` - вывод первой идёт во вторую:

```bash
strings файл | grep flag      # искать флаг в любом файле
```

## Если забыл команду

```bash
grep --help     # краткая подсказка по команде
# или
man grep    # полная документация 
```

🎯 **Тренировка.** Зайди в любую папку (`cd`, `ls`), выбери файл и прогони по нему `file`, затем
`strings файл | grep -i flag`. Привыкни к этим трём командам.
