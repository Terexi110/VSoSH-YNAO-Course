# Глава 2 (easy). Основы терминала Linux

В терминале команды вводят текстом. Начнём с навигации, чтения файлов и поиска.

## Клавиши и редакторы

- `Ctrl + Shift + C` / `Ctrl + Shift + V` — копировать / вставить текст.
- `Ctrl + C` — прервать текущую программу.
- `Tab` — дополнить команду или имя файла: например, `cat sec` до `cat secret_file.txt`, если имя однозначно.
- `↑` / `↓` — история команд.

⚠️ **`Ctrl + Z` не отменяет действие**, а приостанавливает программу. Чтобы вернуться, введи `fg` и нажми Enter.

Для редактирования файла:

| Редактор | Ввод текста | Сохранить и выйти | Выйти без сохранения | Отмена |
|---|---|---|---|---|
| `nano файл.py` | сразу | `Ctrl + O`, Enter, `Ctrl + X` | `Ctrl + X`, затем `N` при запросе (`Y` — сохранить) | `Alt + U` |
| `vim файл.py` | `i` (режим INSERT) | `Esc`, `:wq`, Enter (`w` — запись, `q` — выход) | `Esc`, `:q!`, Enter | — |

В `vim` клавиша `Esc` возвращает из ввода текста в командный режим.

## Где я и что рядом

```bash
pwd            # показать текущую папку
ls             # список файлов
ls -la         # список со всеми файлами (в т.ч. скрытыми) и подробностями
cd папка       # зайти в папку
cd ..          # выйти на уровень выше
```

## Посмотреть файл

```bash
file файл          # узнать настоящий тип файла (картинка? программа? архив?)
cat файл.txt       # вывести содержимое текстового файла на экран
chmod +x prog      # разрешить запуск программы (если file сказал, что это ELF)
./prog             # запустить программу из текущей папки
```

## Две самые полезные команды на CTF

```bash
strings файл          # вытащить читаемый текст из любого файла
grep слово файл       # найти строки со словом
```

Пайп `|` передаёт вывод первой команды второй:

```bash
strings файл | grep flag      # искать флаг в любом файле
```

## Если забыл команду

```bash
grep --help     # краткая подсказка по команде
# или
man grep    # полная документация 
```

🎯 **Тренировка.** Открой папку (`cd`, `ls`), выбери файл и проверь его командами `file` и `strings файл | grep -i flag`.
