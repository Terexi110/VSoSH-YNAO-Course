# Глава 2. Где взять Linux

На туре ВсОШ тебе дадут виртуальную машину с Linux (обычно Kali или Ubuntu) без интернета. Все основные утилиты там консольные, поэтому для подготовки нужен свой рабочий терминал.

| Вариант | Куда ставится | Зачем выбирать |
|---|---|---|
| **WSL 2** | Windows 10/11 | Терминал ставится одной командой, не грузит систему |
| **Виртуальная машина** | VirtualBox / VMware | Точная копия того, что будет на олимпиаде |
| **Вторая система / Live USB** | На диск или флешку | Если мало оперативной памяти и виртуалка лагает |
| **Bandit / Онлайн** | В браузере или по SSH | Если нет прав администратора на школьном ПК |

---

## 1. WSL 2 (самый быстрый способ для Windows)

WSL запускает Linux прямо внутри Windows. Не нужно открывать отдельное окно с тяжелой виртуалкой, а файлы диска C доступны прямо из терминала.

Запусти PowerShell от имени администратора и напиши:

```powershell
wsl --install
```

Команда скачает ядро и поставит Ubuntu. После этого перезагрузи компьютер, открой появившееся приложение Ubuntu и задай логин с паролем.

Если хочешь сразу Kali Linux с предустановленным софтом:

```powershell
wsl --install -d kali-linux
```

Полезные мелочи:
- Твои файлы Windows лежат по пути `/mnt/c/Users/Имя/`.
- Графика работает из коробки: если в терминале набрать `wireshark` или `ghidra`, откроется привычное окно программы.
- Для работы поставь **Windows Terminal** из Microsoft Store: в нем удобные вкладки и нормальный буфер обмена.

⚠️ У WSL свой виртуальный сетевой стек. Специфичные вещи вроде сырых сокетов или режима монитора Wi-Fi могут капризничать, но для 99% задач CTF этого хватает.

## 2. Виртуальная машина (VirtualBox / VMware)

Именно в таком виде задания дают на туре. Главный плюс - виртуалка изолирована от основной ОС. Если ты уронишь систему или запустишь опасный скрипт, Windows никак не пострадает.

Не трать время на установку с ISO-образа через инсталлятор. Есть официальные готовые образы:

1. Поставь бесплатный [VirtualBox](https://www.virtualbox.org/).
2. Скачай готовый образ: [kali.org/get-kali/#kali-virtual-machines](https://www.kali.org/get-kali/#kali-virtual-machines) (выбирай VirtualBox).
3. Распакуй архив, дважды кликни по файлу `.vbox` (или импортируй `.ova`).
4. Запусти машину. Логин: `kali`, пароль: `kali`.

Что сделать сразу:
- Зайди в настройки ВМ: `Устройства -> Общий буфер обмена -> Двунаправленный`. Без этого ты не сможешь копировать текст между системами.
- Сделай снимок (Snapshot) чистой машины. Сломал что-то - откатился за минуту.
- Выдели виртуалке минимум 2 ядра процессора и 3-4 ГБ оперативной памяти.

## 3. Live USB или вторая система

Если на ноутбуке меньше 8 ГБ памяти, виртуалка будет тормозить. В этом случае есть два пути:

- **Live USB с сохранением (Persistence):** запиши Kali Linux на быструю флешку (от 16 ГБ) через утилиту Rufus или Ventoy. В режиме Persistence все файлы и установленные пакеты сохраняются между перезагрузками. Такую флешку можно брать с собой и загружаться с нее на любом ПК.
- **Установка второй системой (Dual Boot):** Linux ставится на свободный раздел диска рядом с Windows. Работает максимально быстро. Но если раньше не ставил системы рядом, будь осторожен с разметкой диска, чтобы случайно не затереть диск с Windows.

## 4. Без установки: Bandit и песочницы

Если прямо сейчас ты сидишь за чужим или школьным компьютером, где ничего нельзя ставить:

- **OverTheWire: Bandit** - лучший интерактивный тренажер командной строки. Подключайся по SSH прямо из командной строки Windows или macOS:
  ```bash
  ssh bandit0@bandit.labs.overthewire.org -p 2220
  ```
  Пароль от первого уровня: `bandit0`. Каждый уровень заставляет использовать реальные команды Linux (`cat`, `find`, `grep`, `strings`).
- **Онлайн-терминалы:** [LabEx Linux Playground](https://labex.io/ru/playgrounds/linux) или [Webminal](https://www.webminal.org/) дают терминал прямо во вкладке браузера.
- **VPS (свой сервер):** можно арендовать дешевый сервер за 150-200 руб. в месяц. Подключаешься по SSH (`ssh root@ip`) и экспериментируешь. Полезно, если захочешь держать своего бота или сайт круглосуточно.

## 5. Какой дистрибутив выбрать

| Дистрибутив | В чем суть | Что в итоге |
|---|---|---|
| **Kali Linux** | Заточен под безопасность: Wireshark, Ghidra, John, Binwalk уже стоят. | На олимпиаде будет именно он. Лучший выбор для виртуалки. Но для повседневной учебы перегружен. |
| **Ubuntu / Debian** | Стандартный, стабильный Linux. Чистая система, любой пакет ставится через `sudo apt install`. | Меньше всего сюрпризов. Отлично подходит для WSL и второй системы. |
| **Arch Linux** | Конструктор, где все настраиваешь руками. | Дает отличный опыт, но требует много времени. Для быстрой подготовки к CTF не нужен. |

## 6. Проверка

🎯 **Тренировка.** Открой свой терминал и проверь, что базовые вещи работают:

```bash
uname -a                         # инфо о системе и ядре
python3 --version                # версия Python
```

Проверь наличие утилит первой необходимости:

```bash
for t in python3 gcc file strings grep xxd curl; do command -v $t >/dev/null && echo "+ $t" || echo "НЕТ: $t"; done
```

Сделай рабочую папку под олимпиаду:

```bash
mkdir -p ~/ctf/{crypto,web,reverse,forensics,misc}
cd ~/ctf && ls -la
```

Если всё на месте - переходи к основам терминала в [easy.md](easy.md).
