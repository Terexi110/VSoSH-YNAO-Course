# Глава 2 (hard). Боевой bash: обработка данных одной строкой

Здесь - то, что превращает терминал в инструмент анализа: `awk`, `sed`, `sort`/`uniq`, `xargs`,
`tr`, циклы, сравнение файлов, перевод систем счисления. Всё проверено на запуск.

## 1. `grep` на максимум

```bash
grep -P '\x50\x4b'   файл        # -P = Perl-регулярки, можно искать по hex-байтам
grep -c flag         файл        # -c = посчитать число совпадений
grep -o -E '\w+@\w+' файл        # -o = вывести только совпадение (тут: почты)
grep -A2 -B2 flag    файл        # показать 2 строки до и после совпадения
grep -rl flag .                  # -l = только ИМЕНА файлов, где есть совпадение
```

## 2. `awk` - работа по столбцам

```bash
awk -F, 'NR>1{print $2}' d.csv        # -F, = разделитель запятая; печатать 2-й столбец, без заголовка
awk '{print $1}' файл                 # первое "слово" каждой строки
awk '{sum+=$1} END{print sum}' nums   # сумма чисел в первом столбце
awk 'length($0)>50' файл              # строки длиннее 50 символов
```

## 3. `sed` - замены и вырезание

```bash
sed 's/СТАРОЕ/НОВОЕ/g' файл      # заменить все вхождения (g = global)
sed -n '10,20p' файл             # вывести только строки 10-20
sed 's/[^0-9]//g' файл           # удалить всё, кроме цифр
```

## 4. Частотный анализ прямо в bash

Для крипто-разведки (сколько каких символов) - без Python:

```bash
grep -o . файл | sort | uniq -c | sort -rn | head
#       ^ разбить на символы  ^ посчитать повторы  ^ по убыванию
```

💡 На кириллице/UTF-8 `grep -o .` иногда сбоит на многобайтовых символах - надёжнее `fold -w1`:
```bash
fold -w1 файл | sort | uniq -c | sort -rn | head
```

## 5. `tr` - быстрые преобразования и ROT13

```bash
echo "uryyb" | tr 'A-Za-z' 'N-ZA-Mn-za-m'   # ROT13 -> hello (сдвиг на 13)
tr -d '\n' < файл                            # убрать переводы строк
tr 'a-z' 'A-Z' < файл                        # в верхний регистр
```

## 6. Перевод систем счисления без Python

```bash
echo $((16#ff))      # hex -> dec  ->  255
echo $((2#1010))     # bin -> dec  ->  10
printf '%x\n' 255    # dec -> hex  ->  ff
printf '%o\n' 8      # dec -> oct  ->  10
```

hex-строка <-> байты и разворот строки - тоже без Python:
```bash
echo '666c61677b6865787d' | xxd -r -p   # hex-строка -> flag{hex}
echo -n 'flag{hex}' | xxd -p            # байты -> hex
echo '}galf{' | rev                     # перевернуть строку -> {flag}
```

## 7. `find` + `xargs` - массовые операции

```bash
find . -type f -print0 | xargs -0 grep -l flag   # -print0/-0 = безопасно для имён с пробелами
# (то же самое короче и безопаснее: grep -rl flag .)
find . -name '*.zip' -exec unzip {} \;       # распаковать все zip
find . -type f -size +1M                     # файлы больше 1 МБ (где прячут вложения)
```

## 8. Сравнение и поиск различий

```bash
cmp a b                      # есть ли различие и где (первый отличающийся байт)
diff <(xxd a) <(xxd b)       # побайтовое различие двух файлов (process substitution)
xxd a > a.hex; xxd b > b.hex; diff a.hex b.hex
```

💡 `<(команда)` - это *подстановка процесса*: вывод команды подаётся как "файл". Так можно сравнивать
результаты двух команд напрямую.

## 9. Циклы - перебор вариантов

```bash
for k in $(seq 0 255); do                     # перебрать ключи 0..255
    echo -n "ключ $k: "
    # ... тут твоя команда с $k ...
done

while IFS= read -r line; do echo "строка: $line"; done < файл   # IFS= и -r = не терять пробелы и обратные слеши
```

## 10. Свои функции (чтобы не повторяться)

Положи в `~/.bashrc` и получишь команду на все сессии:

```bash
ctfscan() { file "$1"; strings -n 5 "$1" | grep -iE 'flag|\{.*\}'; strings -e l "$1" | grep -iE 'flag|\{.*\}'; xxd "$1" | head; }
#  strings -e l дополнительно ловит строки в UTF-16LE (Windows-бинарники и дампы памяти)
# использование: ctfscan задача.bin
```

🎯 **Тренировка (hard).** Возьми текстовый файл, посчитай в нём частоту символов одной строкой
(`grep -o . файл | sort | uniq -c | sort -rn`), затем переведи любое число из hex в dec через
`echo $((16#...))`. Собери свою функцию `ctfscan` в `~/.bashrc`.
