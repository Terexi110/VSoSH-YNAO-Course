# Глава 2. Выживание в Linux (терминал)

Терминал - главный инструмент. Не нужно знать сотню команд - нужно знать **десять** и уметь их
соединять. Ниже ровно те, что реально работают на CTF. Каждую - повтори руками.

## 2.1. Навигация: где я и что вокруг

| Команда | Что делает |
|---|---|
| `pwd` | показать текущую папку (**p**rint **w**orking **d**irectory) |
| `ls` | список файлов |
| `ls -la` | список со **всеми** файлами (в т.ч. скрытыми) и подробностями |
| `cd папка` | зайти в папку |
| `cd ..` | подняться на уровень вверх |
| `cd` | вернуться в домашнюю папку |
| `mkdir имя` | создать папку |
| `find . -name '*.png'` | найти файлы по маске, начиная с текущей папки |

💡 **Скрытые файлы** (имя с точки, например `.secret`) не видны в обычном `ls` - только в
`ls -la`. На CTF секрет часто прячут именно в скрытом файле или в папке `.git`.

**`find` - найти файл, когда не знаешь, где он:**

```bash
find . -type f                   # перечислить ВСЕ файлы в дереве от текущей папки
find . -name '*.txt'             # только .txt
find / -name 'flag*' 2>/dev/null # искать по всей системе; 2>/dev/null прячет ошибки доступа
```

🎯 **Тренировка 2.** Создай папку, в ней - обычный файл и скрытый (`touch видно.txt .невидно`).
Убедись, что `ls` показывает один, а `ls -la` - оба. Найди скрытый через `find . -name '.*'`.

## 2.2. Читать и искать внутри файлов - сердце форензики

Шесть команд, которые нужно знать как таблицу умножения:

| Команда | Что делает |
|---|---|
| `cat файл` | вывести весь файл (для коротких текстов) |
| `less файл` | листать длинный файл (выход - `q`, поиск - `/слово`) |
| `grep слово файл` | найти строки, где встречается `слово` |
| `strings файл` | вытащить **читаемый текст** из бинарного файла |
| `file файл` | определить **тип** файла по его содержимому |
| `xxd файл` | показать файл побайтово (hex + ASCII) |

### `file` - чем файл является на самом деле

⚠️ Расширение (`.jpg`, `.txt`) **врёт**. Файл `photo.jpg` может оказаться zip-архивом. `file`
смотрит внутрь, на "магические байты", и говорит правду:

```bash
$ file *
secret.png:   PNG image data, 800 x 600, 8-bit/color RGB
program:      ELF 64-bit LSB executable, x86-64, ... stripped
dump.pcap:    pcap capture file          # <- сетевой дамп!
notes.txt:    ASCII text
```

За одну команду узнаёшь, где картинка, где исполняемый бинарник (`ELF`), где дамп трафика - и
задачи сами раскидываются по категориям.

💡 **Магические байты** - первые байты файла, по которым виден настоящий тип:

| Начало файла (hex) | В ASCII | Тип |
|---|---|---|
| `FF D8 FF` | `.JPG` | JPEG |
| `89 50 4E 47` | `.PNG` | PNG |
| `50 4B 03 04` | `PK..` | ZIP (а также docx/xlsx/apk - это тоже zip!) |
| `7F 45 4C 46` | `.ELF` | ELF (исполняемый Linux) |
| `25 50 44 46` | `%PDF` | PDF |

```bash
$ xxd secret.png | head -1
00000000: 8950 4e47 0d0a 1a0a 0000 000d 4948 4452  .PNG........IHDR
#         89 50 4e 47 - да, настоящий PNG
```

💡 Если `file`/магические байты показали архив (или он "приклеен" к картинке) - распакуй
(`unzip файл`, `tar -xf файл`, `7z x файл`) либо достань вложения `binwalk -e файл` (подробно - глава 5).

### `strings` + `grep` - главная связка

**`strings`** вытаскивает из любого (даже бинарного) файла последовательности печатных символов.
**`grep`** оставляет нужное. Вместе находят флаг в заметной доле задач:

```bash
strings файл | grep -i flag      # -i = игнорировать регистр (FLAG=flag=Flag)
strings файл | grep '{'          # ищем фигурную скобку флага
strings -n 8 файл                # только строки от 8 символов (меньше мусора)
```

### `grep` - ключи, которые экономят часы

```bash
grep -r flag .             # -r = рекурсивно, во всех файлах всех подпапок
grep -i -n flag файл       # -n = показать номера строк
grep -a flag бинарник      # -a = искать текст даже в бинарном файле
grep -E 'flag\{.*\}' файл  # -E = регулярка: "flag{ что угодно }"
```

💡 "Найти флаг где угодно в папке" одной строкой (регуляркой "слово{...}"):

```bash
grep -raioE '[a-zA-Z0-9_]+\{[^}]+\}' .   # -i = ловить и CAPS-префиксы (FLAG{...}), -o = только совпадение
```

### `xxd` - смотреть байты руками

Нужно, когда файл "битый" или данные спрятаны в его структуре:

```bash
xxd файл | head -20        # первые 20 строк
xxd файл | less            # листать весь дамп (поиск /, выход q)
xxd -s 100 -l 32 файл      # 32 байта, начиная со смещения 100
```

Слева смещение, в центре байты в hex, справа они же как ASCII (непечатные - точкой).

🎯 **Тренировка 3.** Создай текстовый файл с флагом внутри длинного мусора
(`echo "...много текста... flag{try_me} ...ещё текст..." > t.txt`) и научись доставать флаг
тремя способами: `grep flag t.txt`, `grep -oE 'flag\{[^}]+\}' t.txt`, `strings t.txt | grep '{'`.

## 2.3. Пайпы `|` и перенаправление `>` - суперсила терминала

**Пайп `|`** отдаёт вывод одной команды на вход другой - так из простых команд собираются мощные
цепочки:

```bash
strings файл | grep flag | head            # вытащить строки -> отфильтровать -> показать начало
cat words.txt | sort | uniq -c | sort -rn  # посчитать повторы строк и отсортировать по убыванию
```

**Перенаправление вывода:**

```bash
команда > файл.txt    # записать вывод в файл (перезаписать)
команда >> файл.txt   # дописать в конец
команда 2>/dev/null   # выбросить ошибки (поток 2) в "никуда"
```

Полезные "хвосты" для пайпов: `head -n 20`, `tail -n 20`, `sort`, `uniq -c`, `wc -l`,
`tr 'a-z' 'A-Z'` (замена символов).

💡 Частый пайп - декодировать Base64 прямо в терминале (мастхэв на CTF):
```bash
echo 'ZmxhZ3tiYXNlNjR9' | base64 -d     # -> flag{base64}
base64 -d encoded.txt > flag.bin        # декодировать файл
```

🎯 **Тренировка 4.** Собери цепочку: вытащи строки из любого бинарника из `/bin/`, оставь только
длинные (`strings -n 10`), отсортируй, посчитай, сколько их (`| wc -l`), и сохрани в файл (`> out.txt`).

## 2.4. Когда забыл ключи - `man` и `--help`

Наизусть помнить всё не нужно. Два способа вспомнить офлайн:

```bash
grep --help          # краткий список ключей (быстро)
man grep             # полное руководство (листать стрелками, /слово - поиск, q - выход)
xxd --help | grep -i seek   # если справка большая - профильтруй её грепом
```

## 2.5. Чеклист главы

```bash
file *                            # что за файлы?
strings * | grep -i '{'           # флаг лежит открыто?
grep -raoE '\w+\{[^}]+\}' .       # флаг где-то в папке?
xxd файл | head                   # магические байты, структура
```

Если ни одна строка не дала флаг - файл "хитрый", и дальше в дело идут Python и тематические главы.
