# Глава 4 (easy). Криптография - самая база

Крипто-задача: дан зашифрованный текст, надо получить исходный (флаг).

## Сначала отличи кодировку от шифра

- **Кодировка** - просто другой вид записи, ключ не нужен, раскодируется всегда.
- **Шифр** - текст скрыт, нужен ключ или подбор.

## Base64 - самое частое

Признак: буквы, цифры и `=` в конце, например `ZmxhZw==`.

```python
>>> import base64
>>> base64.b64decode("ZmxhZw==")
b'flag'
```

## Hex - тоже кодировка

Признак: только символы `0-9 a-f`, например `666c6167`.

```python
>>> bytes.fromhex("666c6167")
b'flag'
```

## XOR с числом (если ключ дан в условии)

Иногда в условии сказано "каждый байт поксорили с числом 42". Расшифровка - тот же XOR
(наложить тот же ключ ещё раз):

```python
data = bytes.fromhex("4c464b4d")
print(bytes(b ^ 42 for b in data))   # -> b'flag'
```

## Шифр Цезаря - сдвиг букв

Каждая буква сдвинута на одно и то же число. Ключей мало - пробуем все 26 сдвигов и ищем читаемое:

```python
import string
low = string.ascii_lowercase
ct = "khoor"                 # зашифрованное слово
for sh in range(26):
    print(sh, "".join(low[(low.index(c)-sh) % 26] if c in low else c for c in ct))
# при sh=3 получится "hello"
```

Среди 26 строк глазами найди осмысленную - это и есть ответ.

🎯 **Тренировка.** Раскодируй `base64.b64decode("Y3J5cHRv")`. Потом перебери сдвиги Цезаря для слова
`"iodj"` и найди, что получится (подсказка: это `flag`-слово со сдвигом).
