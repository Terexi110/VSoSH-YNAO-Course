# Глава 4 (easy). Основы криптографии

В криптозадаче нужно восстановить исходный текст, обычно флаг.

## Сначала отличи кодировку от шифра

- **Кодировка** меняет запись данных; для декодирования ключ не нужен.
- **Шифр** скрывает текст; для расшифровки нужен ключ или атака на схему.

## Base64 - самое частое

Признак: латинские буквы, цифры, `+`, `/`, иногда `=` в конце. Пример: `ZmxhZw==`.

```python
>>> import base64
>>> base64.b64decode("ZmxhZw==")
b'flag'
```

## Hex - тоже кодировка

Признак: только символы `0-9 a-f`, например `666c6167`.

```python
>>> bytes.fromhex("666c6167")
b'flag'
```

## XOR с числом (если ключ дан в условии)

Если каждый байт поксорили с 42, для расшифровки примени тот же XOR ещё раз:

```python
data = bytes.fromhex("4c464b4d")
print(bytes(b ^ 42 for b in data))   # -> b'flag'
```

## Шифр Цезаря - сдвиг букв

Каждая буква сдвинута на одно и то же число. Ключей мало - пробуем все 26 сдвигов и ищем читаемое:

```python
import string
low = string.ascii_lowercase
ct = "khoor"                 # зашифрованное слово
for sh in range(26):
    print(sh, "".join(low[(low.index(c)-sh) % 26] if c in low else c for c in ct))
# при sh=3 получится "hello"
```

🎯 **Тренировка.** Декодируй `"Y3J5cHRv"` через `base64.b64decode`, затем перебери сдвиги Цезаря
для `"iodj"`. Подсказка: зашифровано слово `flag`.
