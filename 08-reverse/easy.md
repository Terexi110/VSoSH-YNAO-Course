# Глава 8 (easy). Реверс - самая база

**Реверс** - понять, что делает данная программа, и найти нужный ввод (пароль/флаг).

## Если дали скрипт (Python/JS) - просто прочитай его

Пароль часто написан прямо в коде:

```python
password = input("Пароль: ")
if password == "sup3r_secret":      # <- вот он, прямо в коде
    print("flag{...}")
```

Открываешь файл текстом - и смотришь, с чем сравнивают.

## Если дали программу (бинарник) - ищи строки

```bash
strings программа | grep -iE 'flag|password|correct|enter'
```

Очень часто там видно подсказки, а иногда и сам пароль/флаг.

💡 Программу полезно и **просто запустить** - посмотреть, что она спрашивает. Скачанный файл в Linux
сначала делают исполняемым:
```bash
chmod +x ./программа
./программа
```

## Главный приём для скриптов

Если пароль не написан прямо, а вычисляется - **вставь `print()`** и выведи то, с чем сравнивают:

```python
secret = chr(115) + chr(51) + chr(99)
print(secret)        # просто печатаем и смотрим, что это
```

## Как думать

Не читай программу целиком. Задай себе три вопроса, именно в таком порядке:

1. **Где программа говорит "правильно"** или печатает флаг?
2. **Что нужно, чтобы она туда дошла** - какое условие стоит перед этим местом?
3. **С чем сравнивают мой ввод** в этом условии?

Ответ на третий вопрос обычно и есть пароль (или прямой путь к нему).

🎯 **Тренировка.** Напиши скрипт с `if ввод == "hello": print("flag{ok}")`. Потом "как реверсер"
найди пароль, просто прочитав код.
