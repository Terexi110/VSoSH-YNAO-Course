## 1. gdb - динамический анализ

Запускаешь программу и смотришь, что происходит в реальном времени:

```bash
gdb ./program
(gdb) break main            # поставить точку останова на main
(gdb) run                   # запустить
(gdb) info functions        # список функций
(gdb) x/20i $pc             # показать 20 инструкций с текущей
(gdb) x/s 0x404040          # показать строку по адресу
(gdb) break *0x401234       # останов на конкретном адресе (напр. перед проверкой)
(gdb) print $rax            # значение регистра (туда часто кладут результат сравнения)
(gdb) continue              # продолжить
```
💡 Удобная надстройка - **pwndbg** или **gef** (если стоит): красиво показывают регистры/стек.
Поставив точку останова на сравнении пароля, можно прочитать правильное значение прямо из регистра.

⚠️ Современные бинарники часто **PIE**: в Ghidra адреса вида `0x00101...`, а в gdb при запуске они
становятся `0x5555...`. Поэтому ставь `break main` по имени (не по адресу), либо `starti` /
`info proc mappings`, чтобы увидеть реальные адреса в памяти.

💡 Дизассемблер есть и без Ghidra - в любом Linux из коробки:
```bash
objdump -d -M intel ./program | less   # весь код в удобном Intel-синтаксисе
```

## 2. Патчинг: убрать проверку

Иногда проще не подбирать пароль, а **вырезать проверку**. В Ghidra/hex-редакторе меняешь условный
переход на безусловный (или на NOP), чтобы `if (wrong)` всегда шёл по ветке "успех". Признак цели -
инструкция `JNZ`/`JE` сразу после сравнения. После правки сохраняешь бинарь и запускаешь - флаг
печатается при любом вводе. (Работает, когда флаг зашит в программе; если он выводится из ввода -
патч не поможет, нужен правильный вход.)

## 3. Обращение проверки перебором каждого байта

Главный приём (из `04-crypto/hard.md` в реверс-постановке): прочитал в Ghidra преобразование и
"эталон" - восстанавливаешь вход. Если символы проверяются независимо, перебирай по байту:

```python
table = [0x59,0x4f,0x49,0x58,0x4f,0x5e,0x13,0x13]   # "эталон" из кода
def transform(x):                                    # то, что делает программа с символом
    return (x ^ 0x2A)
flag = []
for t in table:
    for ch in range(256):                            # все варианты входного байта
        if transform(ch) == t:
            flag.append(ch); break
print(bytes(flag))                                   # восстановленный пароль
```

🔺 Сложнее - когда каждый байт зависит от своего **номера** (`i`) или от **соседнего** байта. Если
зависимость только от `i`, байты между собой не связаны - перебор по байту ещё работает:

```python
def transform(x, i):
    return ((x + i*7) ^ 0x2A) & 0xFF     # зависит и от символа, и от позиции i -> перебирай x для каждого i
```

А вот когда байты **связаны друг с другом** (например, `x[i] + x[i+1] == sums[i]`), побайтово уже не
решить - тут и нужен солвер ограничений **z3**: описываешь условия, он находит вход:

```python
# pip install z3-solver (если есть; на олимпиадной ВМ может не быть)
from z3 import *
s = Solver()
x = [BitVec(f"x{i}", 8) for i in range(8)]           # 8 неизвестных байтов
for i in range(8):
    s.add((x[i] ^ 0x2A) == table[i])                 # обычные условия из кода
for i in range(7):
    s.add(x[i] + x[i+1] == sums[i])                  # <- СВЯЗЬ соседних байтов - вот зачем нужен z3
if s.check() == sat:
    m = s.model()
    print(bytes(m[x[i]].as_long() for i in range(8)))   # (table и sums - массивы из кода задачи)
```
Если z3 нет - для несвязанных проверок всегда выручает перебор или обращение формулы руками.

## 4. Упакованные и защищённые бинарники

- **UPX** (частая упаковка): `upx -d program` распакует обратно. Признак - строка `UPX!` в `strings`.
- **Анти-дебаг**: программа проверяет, запущена ли под отладчиком (`ptrace`). Виден вызов `ptrace` в
  `ltrace`/Ghidra; обходится патчем этой проверки.
- **Обфускация строк**: строки собираются/расшифровываются в рантайме - тогда `strings` пусто, но
  `ltrace`/gdb на нужной точке покажет уже расшифрованную строку.

## 5. Другие форматы

- `.pyc` -> `uncompyle6`/`decompyle3` (часто не берут Python 3.9+); универсально и офлайн -
  `python3 -c "import marshal,dis;f=open('x.pyc','rb');f.seek(16);dis.dis(marshal.load(f))"`; для новых версий - `pycdc`.
- `.class` (Java) -> `jd-gui`/`procyon`. `.apk` -> `jadx`.
- `.NET` (.exe) -> `dnSpy`/`ILSpy` (почти исходный C#).
