# Глава 5 (easy). Основы форензики и стего

**Форензика** исследует файлы, диски и трафик, чтобы восстановить данные и события.
**Стеганография** прячет данные в картинке или звуке, скрывая сам факт передачи.

## Всегда начинай с этого

```bash
file картинка.png              # что это за файл на самом деле
strings картинка.png | grep -i flag    # флаг может лежать прямо текстом
```

## Метаданные (данные о файле)

В метаданных фото бывают автор, камера, координаты и комментарий. Проверь их на флаг:

```bash
exiftool картинка.jpg          # показать все метаданные
```

## Спрятанный файл внутри файла

К картинке могли дописать архив. Найти и извлечь его:

```bash
binwalk картинка.png           # показать, что внутри
binwalk -e картинка.png        # извлечь найденное
```

💡 Если `binwalk -e` создал пустую папку или ругнулся - попробуй `foremost -i картинка.png`
или просто `unzip картинка.png` (архив в конце файла unzip находит сам).

## Документы PDF и DOCX

Флаг может быть написан **белым по белому** или закрыт картинкой:
* Нажми **Ctrl+A** и скопируй текст в блокнот: так можно увидеть скрытую надпись.
* `.docx` - ZIP-архив. Распакуй его командой `unzip doc.docx`; основной текст - в `word/document.xml`.
