# Глава 5 (easy). Форензика и стего - самая база

**Форензика** - найти спрятанное в файле. **Стего** - данные спрятаны внутри картинки/звука так,
что не видно.

## Всегда начинай с этого

```bash
file картинка.png              # что это за файл на самом деле
strings картинка.png | grep -i flag    # флаг может лежать прямо текстом
```

## Метаданные (данные о файле)

У фото часто внутри записаны автор, камера, координаты, комментарий - там прячут флаг:

```bash
exiftool картинка.jpg          # показать все метаданные
```

## Спрятанный файл внутри файла

Иногда к картинке "приклеен" архив. Проверить и достать:

```bash
binwalk картинка.png           # показать, что внутри
binwalk -e картинка.png        # извлечь найденное
```

💡 Если `binwalk -e` создал пустую папку или ругнулся - попробуй `foremost -i картинка.png`
или просто `unzip картинка.png` (архив в конце файла unzip находит сам).

## Документы PDF и DOCX

Флаг в документе часто написан **белым по белому** или спрятан за картинкой. Приёмы:
* Открой документ и нажми **Ctrl+A** (выделить всё) -> скопируй в блокнот - скрытый текст проявится.
* `.docx` - это zip-архив: `unzip doc.docx` покажет его внутренности (текст лежит в `word/document.xml`).

🎯 **Тренировка.** Возьми любую картинку, прогони `strings` + `grep`, потом `exiftool`. Посмотри,
какие поля есть в метаданных.
